## Сделать руками (системные настройки — только ты)

### 1. Авто-логон (критично для восстановления после ребута)

Без него после Windows Update / сбоя питания апп будет лежать до твоего возвращения.

1. `Win+R` → `netplwiz` → снять галку **«Требовать ввод имени пользователя и пароля»**
   → OK → ввести пароль дважды.
2. Если галки нет (Windows 11 + Hello): открой `regedit`, в
   `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\PasswordLess\Device`
   поставь `DevicePasswordLessBuildVersion = 0`, перезапусти `netplwiz`.
   Либо используй Sysinternals **Autologon** (хранит пароль в LSA, не открытым текстом):
   https://learn.microsoft.com/sysinternals/downloads/autologon
3. **Тестовый ребут** после включения: перезагрузи ПК и ничего не трогай.
   Ожидание: через ~3 минуты `http://127.0.0.1:8000` отвечает, экран заблокирован.

### 2. Пауза Windows Update до возвращения

Параметры → **Центр обновления Windows** → **Приостановить обновления** → 1 неделя
(до ~24.07). Это убирает главный источник ночных ребутов.

### 3. Опционально: BIOS — включение после отключения света

BIOS/UEFI → Power → **Restore on AC Power Loss** (может называться AC Back,
After Power Failure) → **Power On**. Тогда после отключения электричества ПК
включится сам → авто-логон → апп поднимется.

### 4. Перегрев (июль!)

Софт лёгкий (скан раз в 15 мин), греть будет не он. Правила:

- Продуть системник от пыли, не ставить вплотную к стене/в закрытую тумбу.
- Закрыть тяжёлое: браузер с кучей вкладок, игры, лаунчеры, торренты.
- Монитор выключить кнопкой — на работу не влияет.
- Комнату не оставлять герметично закрытой на солнце, если возможно.
- Опционально, ограничить турбо-нагрев CPU (вернуть: тот же путь, значение 100):
  ```powershell
  powercfg /setacvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCTHROTTLEMAX 95
  powercfg /setactive SCHEME_CURRENT
  ```
- Худший случай — термозащита BIOS выключит ПК. Обратно он включится **только
  кнопкой** (Restore on AC Power Loss тут не поможет — питание не пропадало),
  поэтому профилактика важнее всего.

### 5. Проверка связи перед выходом из дома

- Открой бота в Telegram → `/start` → меню отвечает.
- `http://127.0.0.1:8000` → дашборд, статус ok.
- Экран можно заблокировать `Win+L` (не «Выйти»! выход из сессии убьёт апп).

## Пока ты в отъезде

- Алерты о зависших джобах придут в бот автоматически.
- `/restart` в боте — переподключение Telegram-аккаунтов (не рестарт процесса;
  рестарт процесса делает PulseWatchdog сам).
- Если бот молчит сутки+ и дашборд недоступен — значит ПК выключен
  (свет/перегрев); удалённо не чинится, остальное восстановится само.

## По возвращении

- Отключить автоблокировку: `Disable-ScheduledTask -TaskName PulseAutoLock`
  (или совсем убрать обе задачи: `scripts\uninstall_watchdog.ps1` — но
  PulseWatchdog лучше оставить, он полезен всегда).
- Выключить авто-логон (netplwiz → вернуть галку), если не нужен.
- Возобновить Windows Update.
- Оффлайн-аккаунты `davifd23`, `fsdfsdfdsg34` — решить: переавторизовать
  (`auth_accounts.py`) или убрать из `TELEGRAM_SESSIONS`.
