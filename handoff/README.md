# Передача проекта другу (handoff)

Эта папка — всё, что нужно, чтобы отдать Pulse Desk другу на время отпуска
**без конфиденциальных файлов**. Здесь три файла:

| Файл | Для кого | Зачем |
|------|----------|-------|
| `README.md` | для тебя (владельца) | как собрать и передать чистую копию |
| `ИНСТРУКЦИЯ_ДЛЯ_ДРУГА.md` | для друга | как скачать, настроить и запустить |
| `pack_for_friend.ps1` | для тебя | собирает чистый zip без секретов |

---

## Вариант A (рекомендуется): чистый zip

Включает **все текущие файлы проекта, даже незакоммиченные правки**, но без
секретов. В PowerShell из корня проекта:

```powershell
.\handoff\pack_for_friend.ps1
```

Скрипт:

1. Копирует проект во временную папку, исключая всё конфиденциальное
   (список ниже).
2. Проверяет, что в копию не просочился ни один секретный файл —
   если просочился, zip **не создаётся**.
3. Собирает архив `dist\pulse_desk_clean_<дата>.zip`.

Дальше:

1. Отправь другу этот zip (Google Drive, Telegram — файл обычно небольшой).
2. Инструкция для друга уже внутри архива: `handoff\ИНСТРУКЦИЯ_ДЛЯ_ДРУГА.md`.
   Можно дополнительно скинуть её отдельным файлом.

## Вариант B: доступ к GitHub

Репозиторий: `https://github.com/shinra2314/telegram_ping_watcher`.

1. GitHub → репозиторий → **Settings → Collaborators → Add people** →
   ввести GitHub-ник друга.
2. Друг клонирует репозиторий и переключается на рабочую ветку:

   ```powershell
   git clone https://github.com/shinra2314/telegram_ping_watcher.git
   cd telegram_ping_watcher
   git checkout redesign/bot-aperture
   ```

**Важно:** на момент подготовки этой папки в рабочей копии есть
незакоммиченные изменения (database/, src/pulse_desk/, main.py, новые тесты).
Если друг будет работать через GitHub — **сначала закоммить и запушить**,
иначе он получит устаревшую версию. Вариант A этой проблемы не имеет.

## Что НИКОГДА не передаётся (и что скрипт исключает)

| Что | Почему |
|-----|--------|
| `.env` | все токены и ключи API |
| `*.session`, `*.session-journal`, `sessions/` | полный доступ к твоим Telegram-аккаунтам — как пароль |
| `*.db`, `*.sqlite*` (pulse_desk.db, архив) | твоя база: пинги, ключи доступа, участники бота |
| `logs/`, `app.log*`, `restart_*.log`, `mentions*.jsonl` | могут содержать токены и личные данные |
| `backups/` | копии базы |
| `data/` | рабочие данные, QR-коды авторизации |
| `config/services.json` | реальный манифест сервисов (шаблон `services.example.json` остаётся) |
| `ADMIN_TOKEN` (значение) | полное управление твоей инсталляцией |
| `.git/`, `.venv/`, кэши | не секрет, но не нужны в архиве (в варианте B git есть) |

Друг создаёт **свои** `.env` и session-файлы на своей машине —
это описано в его инструкции.

## Чек-лист перед отъездом

- [ ] Запустить `.\handoff\pack_for_friend.ps1`, убедиться что zip создан без ошибок.
- [ ] Отправить zip другу.
- [ ] (Если вариант B) закоммитить, запушить, добавить друга в Collaborators.
- [ ] Убедиться, что НЕ отправил `.env`, `.session`, `.db` — скрипт это
      контролирует, но при ручной пересылке файлов будь внимателен.
- [ ] Если другу нужен просмотр твоего работающего дашборда (а не своя копия) —
      это отдельный сценарий: `share_with_friends.ps1` + `FRIENDS_GUIDE.md`.
