# Pulse Desk — установка с нуля (инструкция для друга)

Тебе передали копию проекта **Pulse Desk** — приложение, которое следит за
Telegram-каналами: ловит упоминания отслеживаемых юзернеймов, выигрыши и
розыгрыши, и показывает всё в веб-дашборде.

В копии **специально нет** файлов владельца: `.env`, `*.session`, базы данных,
логов. Это секреты уровня пароля. Ты создашь свои собственные — ниже написано как.

## Что понадобится

- Windows 10/11 (на Linux/Mac тоже работает, команды чуть отличаются).
- **Python 3.11 или новее** — <https://www.python.org/downloads/>
  (при установке отметь галочку **Add Python to PATH**).
- Свой Telegram-аккаунт (или несколько) для мониторинга.

## Шаг 1. Скачать проект

**Если тебе прислали zip:** распакуй его в удобную папку, например
`C:\pulse_desk`. Дальше все команды выполняются в PowerShell из этой папки:

```powershell
cd C:\pulse_desk
```

**Если тебе дали доступ к GitHub:**

```powershell
git clone https://github.com/shinra2314/telegram_ping_watcher.git
cd telegram_ping_watcher
git checkout redesign/bot-aperture
```

## Шаг 2. Получить свои ключи Telegram API

1. Открой <https://my.telegram.org/apps> и войди со **своим** номером.
2. Создай приложение (название любое).
3. Сохрани `api_id` и `api_hash` — понадобятся в следующем шаге.

## Шаг 3. Создать конфиг `.env`

```powershell
copy .env.example .env
```

Открой `.env` в блокноте и заполни минимум:

```env
TELEGRAM_API_ID=твой_api_id
TELEGRAM_API_HASH=твой_api_hash

# Имена ТВОИХ сессий (произвольные, латиницей) — под ними создадутся
# файлы логина в папке sessions/ на шаге 5.
TELEGRAM_SESSIONS=my_account

# Какие юзернеймы отслеживать в каналах (с @ или без).
USERNAMES=имя_которое_отслеживаем

# Два разных ДЛИННЫХ случайных пароля (минимум 16 символов каждый).
# ADMIN_TOKEN — твой вход с полным управлением, VIEWER_TOKEN — только просмотр.
ADMIN_TOKEN=придумай-длинный-случайный-токен-1
VIEWER_TOKEN=придумай-длинный-случайный-токен-2
```

Остальные настройки в `.env.example` подписаны комментариями — их можно
не трогать, значения по умолчанию рабочие.

**Не вставляй чужие значения.** Не проси у владельца его `.env`,
`.session`-файлы, базу или `ADMIN_TOKEN` — они не нужны и передавать их нельзя.

## Шаг 4. Установить зависимости и запустить

Самый простой способ — готовый скрипт (сам создаст окружение и всё установит):

```powershell
.\run_local.ps1
```

Либо вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Шаг 5. Авторизовать Telegram-аккаунт

При первом запуске нужно один раз войти в Telegram:

```powershell
.\.venv\Scripts\python.exe auth_accounts.py
```

Следуй подсказкам: номер телефона → код из Telegram → пароль двухфакторки,
если включена.

**Если код не приходит** — выбери в меню вход по QR-коду, затем в Telegram
на телефоне: *Настройки → Устройства → Подключить устройство* и отсканируй
QR из терминала (или открой сгенерированный SVG из папки `data/`).
В меню: `4` — пропустить текущий аккаунт, `5` — завершить авторизацию.

После авторизации в папке `sessions/` появятся `*.session`-файлы —
**это твои пароли**, никому их не отправляй и не коммить в git.

## Шаг 6. Открыть дашборд

Запусти приложение (если ещё не запущено):

```powershell
.\run_local.ps1
```

Открой в браузере:

```text
http://127.0.0.1:8000
```

На странице входа введи свой `ADMIN_TOKEN` из `.env`.

## Проверка, что всё работает

- Дашборд открывается и показывает подключённый аккаунт.
- В разделе сканирования можно запустить скан — появятся упоминания,
  если отслеживаемый юзернейм упоминался в каналах, где сидит твой аккаунт.
- Тесты (по желанию, нужен dev-набор зависимостей):

  ```powershell
  .\.venv\Scripts\python.exe -m pip install pytest pytest-asyncio
  .\.venv\Scripts\python.exe -m pytest
  ```

## Полезное

- `docs\ЗАПУСК.md` — подробная памятка по запуску.
- `CLAUDE.md` и `README.md` — устройство проекта, архитектура, команды.
- Telegram-бот для уведомлений — опционально: создай своего бота у
  [@BotFather](https://t.me/BotFather) и впиши `TELEGRAM_BOT_TOKEN` и свой
  `ADMIN_ID` в `.env`.

## Правила безопасности (коротко)

1. `.env`, `sessions/*.session`, `*.db` — секреты. Не пересылать, не коммитить
   (они уже в `.gitignore`).
2. Не запускай одни и те же `.session`-файлы одновременно с двух IP.
3. Никому не сообщай коды входа Telegram — даже «поддержке».
4. `ADMIN_TOKEN` — только у тебя; друзьям для просмотра — `VIEWER_TOKEN`.
